# Drone Cinema

Générateur d'ambiances sonores cinématiques (drones, pads, bruit) entièrement dans le navigateur.

**Demo :** https://salimadour31-boop.github.io/drone-cinema/

## Fonctionnalités

- Presets d'ambiances : Noir, Désert, Espace, Forêt, Ville, Tension
- Contrôles volume, clarté (filtre), densité d'oscillateurs
- Visualiseur live
- Sons synthétisés via Web Audio API (aucun fichier audio externe)
- Multilingue : Français, English, Taqbaylit
- 100 % local, aucune donnée envoyée
- Responsive, thème sombre

## Usage

Ouvrez `index.html` dans un navigateur moderne (Chrome, Firefox, Edge, Safari) ou la démo GitHub Pages.

Cliquez sur un preset puis ▶ Jouer. Ajustez les curseurs. ■ Arrêter pour stopper.
